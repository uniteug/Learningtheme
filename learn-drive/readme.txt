Thème bloc pour les sites d'apprentissage : cours, quiz, examens blancs, fiches, actualités par rubrique et guides pratiques.

== Description ==

Learn & Drive est un thème bloc (Full Site Editing) pensé d'abord pour le permis de conduire, et utilisable pour toute matière (code bateau, langues, physique, certifications).

* Thème bloc pur : aucun constructeur de pages, aucune police distante, aucun jQuery.
* 5 ambiances livrées comme variations de style : Route claire (défaut), Coach, Magazine, Neutre, Route de nuit.
* Mode sombre automatique (préférence système) et bascule manuelle, avec une palette sombre par variation.
* 12 couleurs nommées par rôle (fond, surface, texte, primaire, accent, réussite, erreur, premium…), typographie fluide, polices hébergées localement (Atkinson Hyperlegible, Inter, Plus Jakarta Sans, Source Serif 4, Lexend pour la lecture facilitée).
* Gabarits : accueil, page pilier par catégorie, cours, leçon (sommaire collant), question, quiz et examen blanc, fiche panneau et index filtrable, actualité, archive de rubrique, info & démarche, lexique, auteur, recherche, 404.
* Compositions (patterns) : bandeau, choix de la catégorie, quiz par thème, question du jour, actualités, guides, théorie / pratique, témoignages, comparatif gratuit / premium, application, FAQ éditoriale, « Ce qui change pour vous », « En résumé », étapes, tableau de coûts, emplacement publicitaire à hauteur réservée.
* Accessibilité : focus visible, zones tactiles de 44 à 56 px, contrastes AA, animations réduites sur demande.

Le thème fonctionne seul. Les cours, quiz, données structurées et sitemaps avancés sont fournis par le plugin compagnon « Learn & Drive Core ».

== Installation ==

1. Apparence › Thèmes › Ajouter › Téléverser le fichier zip du thème, puis Activer.
2. Installer le plugin compagnon « Learn & Drive Core » pour les quiz et contenus d'apprentissage.
3. Apparence › Éditeur › Styles pour choisir une variation, les couleurs et les polices.

== Frequently Asked Questions ==

= Le thème charge-t-il des ressources externes ? =

Non. Polices, icônes et scripts sont servis par votre site.

= Comment passer d'une ambiance à l'autre ? =

Apparence › Éditeur › Styles › Parcourir les styles.
